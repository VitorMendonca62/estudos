Os conectivos lógicos são operadores verdade-funcionais (funções de valoração) que constroem proposições compostas a partir de proposições atômicas. Seu sentido convencional na matemática é puramente extensional — determinado de forma unívoca pelos **valores-verdade** de suas partes componentes, sem dependência de nexos de causalidade, tempo ou contexto do mundo real.
### 1. Análise Avançada dos Operadores
Dadas as proposições atômicas $P$ e $Q$, pertencentes ao conjunto de valores $V = \{\text{V}, \text{F}\}$ (ou $\{1, 0\}$), os operandos relacionam-se sob a seguinte tabela de valoração convencional:
- **Negação ($\neg P$ ou $\sim P$):** Operador unário. Inverte estritamente o valor de verdade de $P$.

| **P** | **Q** | **Negação (¬P)** |
| ----- | ----- | ---------------- |
| **V** | **V** | F                |
| **V** | **F** | F                |
| **F** | **V** | V                |
| **F** | **F** | V                |

- **Conjunção ($P \land Q$):** Verdadeira **apenas** se ambos os operandos forem verdadeiros simultaneamente. Equivale ao produto lógico ($P \cdot Q$).

| **P** | **Q** | **Conjunção (P∧Q)** |
| ----- | ----- | ------------------- |
| **V** | **V** | **V**               |
| **V** | **F** | F                   |
| **F** | **V** | F                   |
| **F** | **F** | F                   |

- **Disjunção Inclusiva ($P \lor Q$):** Falsa **apenas** se ambos os operandos forem falsos. A verdade de um não exclui a verdade do outro (sentido matemático padrão). Equivale à soma lógica.

| **P** | **Q** | **Disjunção Inclusiva (P∨Q)** |
| ----- | ----- | ----------------------------- |
| **V** | **V** | **V**                         |
| **V** | **F** | **V**                         |
| **F** | **V** | **V**                         |
| **F** | **F** | F                             |

- **Disjunção Exclusiva/XOR ($P \underline{\lor} Q$ ou $P \oplus Q$):** Verdadeira se os operandos tiverem **valores-verdade distintos**. Equivale a $\neg(P \leftrightarrow Q)$.

| **P** | **Q** | **Disjunção Exclusiva (P∨​Q)** |
| ----- | ----- | ------------------------------ |
| **V** | **V** | F                              |
| **V** | **F** | **V**                          |
| **F** | **V** | **V**                          |
| **F** | **F** | F                              |

- **Condicional / Implicação Material ($P \rightarrow Q$):** Falsa **apenas** quando o antecedente ($P$) é verdadeiro e o consequente ($Q$) é falso (caso **V $\rightarrow$ F**).
    - _Vacuidade:_ Qualquer condicional com antecedente falso ($P = \text{F}$) é **vacuamente verdadeira**, independentemente do valor de $Q$.
    - _Equivalências Chaves:_ $P \rightarrow Q \equiv \neg P \lor Q \equiv \neg Q \rightarrow \neg P$ (contrapositiva).

| **P** | **Q** | **Condicional (P→Q)** |
| ----- | ----- | --------------------- |
| **V** | **V** | **V**                 |
| **V** | **F** | **F**                 |
| **F** | **V** | **V**                 |
| **F** | **F** | **V**                 |

- **Bicondicional / Equivalência Material ($P \leftrightarrow Q$):** Verdadeira se ambos os operandos possuírem o **mesmo valor-verdade**. Equivale a $(P \rightarrow Q) \land (Q \rightarrow P)$.

| **P** | **Q** | **Bicondicional (P↔Q)** |
| ----- | ----- | ----------------------- |
| **V** | **V** | **V**                   |
| **V** | **F** | F                       |
| **F** | **V** | F                       |
| **F** | **F** | **V**                   |
### 2. Propriedades Álgebra-Booleanas Fundamentais
Os conectivos lógicos operam sob as propriedades formais da Álgebra de Boole:
- **Comutatividade:**
    - $P \land Q \equiv Q \land P$
    - $P \lor Q \equiv Q \lor P$
    - $P \leftrightarrow Q \equiv Q \leftrightarrow P$
    - _(Nota: O condicional $P \rightarrow Q$ **não** é comutativo)_.
- **Leis de De Morgan:**
    - $\neg(P \land Q) \equiv \neg P \lor \neg Q$
    - $\neg(P \lor Q) \equiv \neg P \land \neg Q$
- **Negação do Condicional:**
    - $\neg(P \rightarrow Q) \equiv P \land \neg Q$
- **Distributividade:**
    - $P \land (Q \lor R) \equiv (P \land Q) \lor (P \land R)$
    - $P \lor (Q \land R) \equiv (P \lor Q) \land (P \lor R)$
